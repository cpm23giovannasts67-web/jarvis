JARVIS PWA

Esta versão é uma interface web instalável (PWA).

IMPORTANTE: para aparecer a opção "Instalar aplicativo" no Chrome, o projeto precisa ser servido por HTTPS ou por localhost. Abrir o index.html diretamente como arquivo permite testar a interface, mas pode não habilitar a instalação PWA.

No celular, uma forma simples de testar é hospedar estes arquivos em um serviço de hospedagem estática com HTTPS. Depois abra a página no Chrome e use o menu > Adicionar à tela inicial / Instalar aplicativo.

A versão atual funciona localmente com comandos básicos e reconhecimento de voz quando suportado pelo navegador. O cérebro de IA/API será conectado em uma próxima etapa.
